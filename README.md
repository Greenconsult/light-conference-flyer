# The Light Conference — I Will Be Attending flyer

This is a **single-file website**. Upload `index.html` to a GitHub repository. The flyer image is embedded directly in the HTML, so you do not need to upload the `assets` folder.

## Publish using GitHub Pages
1. Create a public GitHub repository.
2. Upload **index.html** at the repository root.
3. Open Settings → Pages → Build and deployment.
4. Select Deploy from a branch, main, / (root), and Save.
5. Visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

Visitors can upload and drag/zoom their photos and download a personalised PNG. Their photos are processed locally in the browser.
